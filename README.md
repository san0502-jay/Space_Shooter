# Space Shooter

A simple 2D space shooter game built using C++ and raylib.

## Features

- Smooth player movement
- Delta-time based movement system
- Bullet shooting system
- Enemy spawning system
- Enemy collision detection
- Score system
- Game over system
- Pause and resume system
- Entity cleanup system
- Multi-file game architecture

## Controls

| Key | Action |
|------|--------|
| W / ↑ | Move Up |
| S / ↓ | Move Down |
| A / ← | Move Left |
| D / → | Move Right |
| SPACE | Shoot |
| Mouse Left Click | UI Buttons |

## Technologies Used

- C++
- raylib
- CMake
- CLion

## Concepts Learned

This project helped practice:

- Game loops
- Delta time movement
- Entity systems
- Collision detection
- Object-oriented programming
- Dynamic object spawning
- State machines
- Rendering order
- Entity lifecycle management
- Multi-file architecture


## Build Instructions

```bash
mkdir build
cd build
cmake ..
cmake --build .
```
